元件接數據：實際範例

下面每個元件都掛在普通網頁裡。拖拉滑桿、按按鈕，元件會平順變成新數字；右邊「模擬即時資料」那組是程式每 2 秒自己送新數據進去。

模擬即時資料：每 2 秒進一筆新數字，折線與大數字一起更新。

講到哪、元件就長到哪

解說型動態元件由 step 決定長到第幾步。拖動滑桿就像講者講到不同段落，三個元件一起往下長（實際使用時由你的剪輯或播放程式傳入）。

程式碼

<link rel="stylesheet" href="lib/ms.css">
<script src="lib/widgets.js"></script>  <!-- widgets2.js、widgets3.js、widgets-all.js、names.js、ms.js 依序載入 -->

const hr = MS.mount('#hr', 'heart-rate', { value: 88 });
hr.update({ value: 120 });   // 數字會平順過渡到 120
